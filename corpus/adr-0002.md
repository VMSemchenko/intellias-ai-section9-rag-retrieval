# ADR-0002: Python and toolchain baseline

**Status:** Active. Reviewed every June.

## Decision

All backend services target **Python 3.12**. 3.13 is permitted for new services only
after the platform base image ships it, currently planned for Q1 2027.

| Concern | Choice |
|---|---|
| Runtime | Python 3.12 |
| Dependency management | `uv`, lockfile committed |
| Formatting and linting | `ruff` — one tool, no `black`/`isort`/`flake8` stack |
| Type checking | `mypy --strict` on new modules, advisory on legacy |
| Test runner | `pytest` |
| HTTP client | `httpx`, through the platform wrapper that enforces ADR-0055 |
| Base image | `python:3.12-slim`, mirrored internally |

## Rationale

One runtime version across services makes the shared libraries tractable. We tried
supporting two minor versions in 2024 and spent more time on compatibility shims than the
flexibility was worth.

`ruff` replaced a four-tool stack. The migration took an afternoon and removed a class of
CI failures caused by tools disagreeing with each other.

## Consequences

A service pinned to an older minor version cannot consume current platform libraries and
must be brought forward before its next dependency bump. There are currently no services
below 3.12.
