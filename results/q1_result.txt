The 502 error is produced because the outbound connection pool in `checkout-svc` saturated under load after the v4 auth migration. Specifically, the v4 token exchange added more outbound HTTPS requests, but `checkout-svc` was still using the default `httpx` pool size of 10 connections. This led to request queues forming when the pool was saturated, and requests failing to acquire a connection within the client timeout, resulting in a `502 Bad Gateway` error at the edge gateway [rb-checkout-502#0].
